# Бэкапы сервера

Каждую ночь в 03:00 таймер `brain-backup.timer` делает снимок базы и папки blobs.
Архив шифруется `age` и уходит в облако через `rclone`.

## Восстановление из бэкапа

1. Скачать последний архив из облака.
2. Расшифровать ключом из сейфа.
3. Запустить `restore-check.sh` и затем `brain doctor`.
